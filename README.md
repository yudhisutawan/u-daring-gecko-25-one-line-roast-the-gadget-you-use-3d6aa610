One-line roast of a daily gadget for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty ($5 prize pool, top 3). The program writes a single joke — the phone's autocorrect turned "meeting at 3" into "mating at 3", HR has questions, and the phone has no comment — to `entry.txt`. The joke is the winner of a 10-candidate head-to-head tournament judged with the competition's own judge brief: undefeated (9 wins, 0 losses).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
